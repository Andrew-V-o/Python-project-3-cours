# Консольное приложение управления списком студентов

Приложение на Python 3.9+ для загрузки, вычисления среднего балла, редактирования и экспорта оценок студентов в формате CSV.

## Структура проекта
- `lab/` — исходный код приложения (модели, логика, обработка ошибок, CLI)
- `data/` — примеры файлов CSV
- `tests/` — автотесты на pytest

## Запуск приложения
```bash
python -m lab.main
